## Task, samples and donors

Each sequence contains four distinct sampled key/value pairs and one final query key selected uniformly from those four. Keys and values are sampled independently without replacement from separate vocabularies of 16 tokens each. The answer is one of 16 value classes. Uniform full-vocabulary chance accuracy is **6.25%**; uniformly choosing one of the four displayed values yields **25%**. Report accuracy by each of the four queried pair positions.

Discovery contains **1,024** recipient cases, input seed **2000001**. Confirmation contains **2,048** recipient cases, input seed **3000001**. Batch size is **128**. The same recipient/donor pairs are shared across model seeds 0, 1 and 2. Donor selection uses an independent generator seeded with input seed + **10000000**; it selects one of the three other pairs uniformly. Confirmation donor generation is independent of the discovery donor stream. These are independently generated streams, not a guarantee of disjoint finite samples before audit.

An active key donor exchanges the two key tokens at the queried and selected other pair, leaving value tokens, query token and positions unchanged. An active value donor exchanges the values at those pairs, leaving keys and query unchanged. Both change the correct answer to the selected other recipient value, which defines the alternative target. Matched key and value donors instead exchange the remaining two pairs, preserving the queried association and correct answer. Their alternative target is still the active donor's alternative, so all families share the same measured contrast.

## Interventions and controls

The scientific L1/L2 correspond to code layers 0/1. L1 residual interventions use the output after attention and MLP. L2 Q/K/V are projections of the layer-normalized incoming residual, patched before attention scores or value aggregation. Every transplant copies all features and heads from untouched donor forward passes. The four same-donor joint conditions each use one donor; the prespecified cross-donor condition uses the two distinct active donors specified below. A composite tensor copies only each case's designated positions and leaves the rest at recipient values. Joint patches are simultaneous within one subsequent recipient forward pass.

Each of the four donor families has these nine familiar sites: `l1_resid_values`, `l1_resid_query`, `l2_k_values`, `l2_q_query`, `l2_v_values`, `l2_k_keys`, `l2_q_values`, `l1_resid_wrong_values`, `l2_k_wrong_values`. Four wholly unevaluated combinations are added only in confirmation: `joint_l2_kq`, `joint_l2_kv`, `joint_l2_qv`, `joint_l1_values_query`, with constituents fixed in `evaluate.py`. A fifth unseen composition condition, `cross/keyK_valueV`, simultaneously uses L2 K from the active key-swap donor and L2 V from the active value-swap donor at their shared exchanged value positions. It was selected after discovery but before confirmation to distinguish a routing/content cancellation prediction (effect zero) from the additive discovery baseline (approximately two). Its full-donor comparator is an untouched input with both keys and values exchanged, retaining the original queried answer. Total: **53 conditions per seed** and **159 mean forecasts**.

Active site positions follow the exchanged pairs. Wrong-position controls use the complementary two value positions. In matched families the exchanged pairs are irrelevant to the query, while their complementary wrong-position pair includes the queried association; this is not a perfectly same-position matched comparison. Wrong-component controls are the alternate Q/K/V pathways; a component is not intrinsically a negative control when another donor manipulation predicts its effect. L2 Q at nonquery value positions is structurally incapable of affecting the final token in this architecture and is a locality check only.

Recipient-to-itself patches must reproduce unpatched logits with maximum absolute error **<= 1e-6**. Report the maximum at every evaluated site, including each same-donor joint patch. Cross-donor recipient-to-itself behavior has the same component/position set as joint_l2_kv and is covered by that labeled runtime no-op check. Prospective implementation tests also cover donor isolation, patch position indexing, causal masking, exact cache boundaries, and joint composition. A failed control is reported and prevents an unqualified mechanism conclusion; do not filter the affected cases. Retain unpatched recipient and all donor behavior, original-answer rates, alternative-answer rates and per-condition uncertainty.

## Outcomes, scoring and uncertainty

The primary effect for a case is `(P(alternative)-P(original))_patched - (P(alternative)-P(original))_recipient`, bounded by [-2, 2]. Forecasts concern its mean within each fixed model and condition, not individual answers or individual-case effects. The primary mechanism contrast is the mean paired difference **key/l2_k_values minus key/l2_q_query**. The frozen quantitative rule, acceptance bounds, all-seed decision gates, alternatives and falsification conditions are in `PREDICTION.md` and machine-readable `predictions.json`.

The primary forecast loss is the equally weighted **mean squared error over all 53 condition means**, separately for each seed. Secondary loss is individual-case MSE.
