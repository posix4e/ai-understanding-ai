Original small-model study / 3 October 2026

A small AI repair that worked on new models.

Changing the order of a list made small AI models give wrong answers. We blocked selected internal connections. The answers became much more accurate.

A controlled study of a four-pair task. We give the repair the correct pairs and tags that record their original positions.

01 / The idea

A simple task.
A useful failure.

The model must find a value from its label.

Suppose a list contains four pairs. Label A has value 7. Label B has value 4. If we ask for A, the correct answer is 7.

The models learned the original order. They gave correct answers on the original test inputs. But changed orders let some internal parts receive information that they could not receive before.

  1. 1

    Change the order

    The same labels and values appear in a different sequence.

  2. 2

    Change what can reach each part

    Extra labels can now send information to a value. This can lead to a wrong answer.

  3. 3

    Block selected connections

    The repair limits which labels can send information to each value. It needs no additional training.

We supplied the structure. We gave the repair the correct pairs and original position tags. The model did not find those relationships for itself during this test.

02 / What passed

A new test,
set in advance.

Read the plan published before the test ↗

All six new models passed the main requirements.

We published the test rules, inputs, trained models, and predictions before running the new test. We tested every order in the defined group of 105. We also made 624 comparisons using alternative connection patterns across those orders. The comparisons reuse inputs and are not independent tests.

✓

Answers stayed close to the original performance.

We checked each order and each of the four pairs we could ask about. The lowest accuracy was 99.6%.

✓

The choice of connections mattered.

The repair passed the required comparison with the average of the alternative patterns. The alternatives kept the same number of label connections and retained each value's own label.

✓

The saved evidence passed a separate audit.

An independent program checked all 492 raw-data files and reproduced the study's decisions. This was a separate code check within the same research project, not an external replication.

03 / What did not fully work

The errors are
part of the result.

15

Wrong answers in the main test

Five models made no errors. The sixth made 15 errors across 107,520 input-and-order combinations. The errors came from two inputs used in different orders.

One error was severe: the probability of the correct answer fell from about 99.9% to 0.9%. The excellent average did not prevent this failure.

Inspect every wrong answer CSV
2/6

Models missed a further prediction

We put blocked connections back, one at a time. We predicted a minimum average increase for specific wrong answers, measured relative to other wrong answers. Two models did not meet that minimum with the required confidence.

The separate six-model claim for this test failed. It stays in the paper.

04 / A broader, separate test

Other rules also worked.

We tested 2,415 other orders on 256 of the same inputs.

Two rules gave correct answers in every tested case, in all six models. At the first internal processing stage, one rule let each value receive information only from itself and its own label.

The models could answer correctly even when their internal processing differed from the original order. We still gave the rule the correct pair relationships.

These results apply to the 2,415-order test and its 256 inputs. We did not test this rule across all 2,520 orders on all 1,024 inputs. Repeating the same inputs in many orders does not create millions of independent examples.

05 / GPT-2 follow-up

The first-layer repair did not transfer.

Read the follow-up report ↗

We tested a pretrained model with 124 million parameters.

GPT-2 has about 1,760 times as many learned numbers as our small models. It has 12 processing layers. We tested 512 four-pair lists under 15 conditions. We did not train the model again.

Higher-precision repeat on the same 512 inputs. Percent of correct next-token answers.
Input and repairAmong 16 choicesAcross the full vocabulary
Original order93.2%86.9%
Changed order, original position tags10.4%0.0%
Changed order, first-layer repair9.6%0.0%

The repair restored the checked value states in the first layer. It did not restore correct final answers. It also failed the required comparison with eight alternative connection patterns.

A numerical problem, kept in the record. The first run narrowly missed two checks for agreement between internal states. We then registered a repeat with more precise arithmetic. That repeat passed the implementation checks and failed all three repair requirements. It reused every input, so it is not an independent confirmation.

Applying the guard in all 12 layers raised 16-choice accuracy to 31.25%. This was a separate test and remained far below the original performance. It did not rescue the first-layer claim.

What this tells usMatching an early internal state can be too little to repair the answer. This result concerns one GPT-2 checkpoint and an artificial change in text order. Size, depth, training, and text format all differ from our small models. We cannot say which difference caused the failure.

06 / What comes next

Test the limits
of the explanation.

Yes. Earlier papers suggest several of these next steps.

The directions below come from the authors. Our exact test of 105 orders and six new models was our own design.

1 October 2026 · Preprint

Check whether an explanation predicts actual behavior.

Geng and colleagues recommend fixed measures of behavior and checks with different scores and interventions. We measured correct answers and answer probabilities. We also tested alternative connections.

Read Geng et al., section 6 ↗

February 2026 · Journal paper / January 2026 · Updated preprint

Test larger models and harder tasks.

Tang and colleagues call for tests in larger, real-world models and more flexible tasks. Arora and colleagues propose real-world tests and questions that require several steps. Our GPT-2 follow-up begins testing a pretrained model. Harder tasks and broader model comparisons remain open.

Read Tang et al., Discussion ↗ · Read Arora et al. ↗

August 2025 · Conference paper

Check other parts of the model.

Wu and colleagues recommend studying how attention works with other internal parts. Tang and colleagues also recommend finding and changing redundant pathways together. We have not completed these broader tests.

Read Wu et al., section 6 ↗

Our proposed next tests: ask another group to repeat the study, use longer lists, and make the repair find pair relationships without our help. These are our specific proposals.

The six models in the original paper each have 70,720 parameters. The separate GPT-2 follow-up tests one much larger pretrained model, while keeping a simple four-pair task. Its first-layer repair failed.

Why this is worth publishingWe turned an explanation into a specific repair. Then we tested it on new models, with rules fixed in advance. The results show where it works and where it fails. This is evidence for a narrow claim that others can check. It is not yet a peer-reviewed finding.
