Can we add a different kind of AI “organ”?

A language model handles words. Could a separate internal module supply rules for how a world changes? We want to test what each part contributes.

Current direction / Different internal parts

A small world model inside a language model.

The small parts learned their rules. The connected system failed. A new offline reader passed a narrow address check.

“Organ” is an analogy for parts with different jobs.

Our module is trained to score which state should follow an action. It gives each possible next state an energy score: lower means a better match. Here, energy is a learned score, not electrical power. A small connector passes this information into the language model while it processes the question.

This is an internal connection. It is different from sending a question to one of several separate models. The language model’s existing weights stay fixed while the connector learns.

01 / Inside Granite

The first clue did not become a general repair.

A correct digit and a correctly formatted answer are different things.

Granite is a mixture-of-experts model, or MoE. It chooses among internal processing parts called experts. We switched off one expert at one layer. We also tested a correction that adjusted the strength of the remaining expert signals.

  1. 1

    A small pilot changed the format.

    One answer changed from a bare digit to a sentence containing the same correct digit. This clue came from one prompt selected during early testing.

  2. 2

    The broader prediction failed.

    We tested 64 new digit lists with two question wordings. The correction helped the format with one wording and hurt it with the other. With the second wording, the unmodified model gave 26 correct answers out of 64. It gave 34 known wrong answers. Some replies could not be scored by the fixed rules. They remain unresolved.

  3. 3

    A wording test also failed its requirements.

    We compared “first” with “leftmost.” We also supplied “Answer:” before some replies. This opening changed the result. The unmodified model’s immediate choice among digits did not meet the requirement for the next planned test.

The complete-answer test stopped.Its required first-step check failed: an initial score array did not match the earlier saved result. We stopped after 814 saved replies. Those replies remain ungraded. The numerical checks below do not supply a complete-answer result or cancel the failed predictions.

02 / Check the numbers

Adding the same numbers can give two results.

A tiny internal difference was followed by many different output scores.

Each expert produces numbers. The model multiplies these numbers by routing weights, then adds the contributions. We checked these steps with saved inputs from one question.

  1. 1

    The same question did not always give the same scores.

    Five of eight fresh program runs produced both earlier score patterns in their three main repeats. The highest-scoring next token stayed the same. We did not generate complete answers in these checks.

  2. 2

    We found the first recorded difference.

    In 27 trace comparisons, the first difference appeared after the fourth layer combined its expert outputs. One of 92,160 internal numbers differed. The earlier recorded expert outputs, routing weights, and input values matched. This was before the layer where we had switched off an expert.

  3. 3

    The combining step reproduced both results.

    We tested the saved numbers without running the full model. Multiplication gave identical products. Combining those fixed products on the Apple graphics processor, or GPU, produced both earlier results.

Completed saved-input test. Counts refer to operations; one trial can contain more than one operation.

The two combined outputs differed in one number, by about 0.000244. The GPU also varied when it reused one unchanged product. This narrows the observed variation to the combining code, including memory allocation and addition. It does not identify the exact internal cause.

A later calculation offers a possible explanation.Computers round numbers. We simulated all 40,320 orders for adding eight saved contributions. Rounding during the additions could produce both observed values. This calculation came after the test. We did not measure the GPU’s actual addition order or explain how often each result occurs.

For this one sum, the stable CPU result was not the closest value that the number format could store. A repeatable result is not necessarily the nearest result to an exact sum.

These checks concern one saved input and one software setup. They establish no specialist internal “organ,” new cognitive mechanism, or measured change in complete answers. We make no novelty claim.

03 / Check basic ability

The model first needs to do the task.

A new copy task failed before we changed any expert.

We asked the unchanged model to copy the far-left number from a list of three two-digit numbers. The 24 questions came from eight lists, each shown in three orders. We repeated all 24 questions in a second fresh program run.

Each run needed at least 23 correct answers in the required two-digit format. Each gave eight. A separate code check confirmed the counts.

The one-digit replies ended normally. They were wrong complete numbers. The four wrong two-digit replies copied another number from the list. No reply was unclear under the fixed scoring rules, and none reached the output limit.

The test stopped at this required check.We did not select a comparison expert, run the instrumented repeats, remove an expert, or test the reserved questions. This result applies to this model, prompt, and setup. It cannot tell us what an expert removal would do.

04 / A reliable language behavior

The verb follows the subject.

The language check passed all 96 comparisons in both runs.

Consider “The window near the walls is open.” The subject is one window, so the verb is “is.” The nearby word “walls” is plural. We tested whether the model gives a higher score to the correct verb even when this other noun has a different number.

We fixed 24 noun pairs before the test. Each supplied four sentence pairs: singular or plural subjects, with matching or opposite-number nouns in between. Each candidate sentence changed only “is” to “are,” or the reverse. We scored ordinary text directly, with no instruction to write an answer in a special format.

05 / A prediction check

The measurement test failed.

Correct language choices did not make our internal predictions accurate enough.

We reused two sentences from the language check. We made small changes to one internal vector and compared the measured effect with a prediction from the model’s local slope, called a gradient. We fixed the rules before the test and repeated it in a fresh program run.

The starting values matched. Checks with no internal change kept the original scores. At the tested position, the recorded later expert choices were unchanged across the normal-routing test points. Yet 10 of 12 prediction checks missed the fixed error limit. A separate calculation confirmed the failure. The two passes came from the same sentence, repeated.

The planned larger test stays closed.We cannot use this failed measurement check to explain which experts cause grammar behavior. Rounding and nonlinear responses remain possible contributors. This test does not isolate the cause of the mismatch or establish that the gradient code is wrong.

All 44 model evaluations and 12 gradient calculations completed. No expert removal was returned to the model, no fresh discovery sentences were used, and no provider fees were added. The two reused sentences give a narrow implementation check, not 12 independent scientific examples.

07 / The next goal

Test reading and writing
as separate parts.

A useful explanation must survive a new test.

The copy-and-format idea around expert 9 remains closed. The language task passed, but its follow-up prediction check failed. That failed plan stays closed. Its rules and results stay unchanged.

The second attempt completed, but it failed on the short training questions as well as the longer probes. We cannot describe this as only a failure to combine steps. The current evidence does not isolate why learning failed.

The completed access check did not improve the total number of correct answers when we pointed the frozen connector to the relevant rule. A new offline reader now identifies the requested address on 24 exposed development questions. This is a separate fitted reader, not a repair of the old connection or an explanation of its failure.

Next, a separate writer check would supply an outcome-probability vector and test whether the frozen host can turn it into the right answer. This deliberately supplies an answer code. It is a check of the connection, not evidence of reasoning or a successful organ transplant. Only after separate checks of both parts would we consider joining them with their weights fixed. No next study starts automatically.

A later transplant test would keep the language model and connector fixed, replace only the rule module with one trained on new world rules, and test new action sequences. That test has not run. Even success in four training worlds would not prove transfer to unseen rules.

We do not yet claim a new mechanism, a broadly reliable repair, or a novel research result.
